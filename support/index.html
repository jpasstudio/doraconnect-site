Private-test support

ผู้เข้าร่วมทดสอบที่ได้รับเชิญให้ติดต่อผู้ดูแลผ่านช่องทางส่วนตัวเดียวกับที่ใช้รับคำเชิญ โดยระบุเพียงประเภทคำขอ เช่น ขอส่งออก แก้ไข ยกเลิกสิทธิ์ หรือลบข้อมูล และให้ผู้ดูแลแนะนำวิธียืนยันบัญชีที่เหมาะสมก่อนส่งรายละเอียดเพิ่มเติม

Invited testers should use their existing private invitation channel. There is currently no dedicated private email address or confidential web form published for this project. We do not invent an address or claim to monitor a mailbox that has not been configured. Public onboarding remains closed until the operator identity and a private contact route are confirmed.

General technical questions only

For non-sensitive project questions, you can contact the maintainer through the public DoraConnect documentation issue tracker. A GitHub account may be required. Issues are public: do not include usernames tied to a private request, personal media, passwords, tokens, OAuth codes, account exports, identity documents or payment details.

The maintainer account is jpasstudio. Public issue filing is not a confidential deletion request. Use the private test channel for any personal-data or security matter.

What the public website cannot do
