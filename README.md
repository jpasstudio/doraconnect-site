## Boundaries
GitHub Pages serves documents only, not Login Kit callbacks, webhook receivers or
workspace APIs. The existing private app repository and port 4310 are unchanged.
Do not configure these static documents as OAuth or Webhook endpoints.

The policies accurately describe a private test, including current retention/deletion
limitations. The legal operator identity and dedicated private contact address need
confirmation before public onboarding/Production submission. These pages are not
legal certification or evidence of TikTok approval.

## TikTok URL verification
Use URL-prefix verification for the full project prefix. The actual signature text
file must come from this app's TikTok URL properties panel. Place only that exact
public verification file in the repository root after checking its name and content.
Do not invent a signature or claim ownership of all github.io domains. GitHub Pages
must return the file without authentication or redirects. Keep personal data out of it.
