Privacy Policy

การจัดการข้อมูลของ DoraConnect ในช่วงทดสอบส่วนตัว · Version 6 September 2026

สถานะ: ทดสอบแบบส่วนตัว / Private testing

เว็บไซต์นี้เป็นข้อมูลของโครงการและนโยบาย ไม่ใช่ Workspace ที่เข้าสู่ระบบได้ ไม่มีการสมัครสาธารณะหรือรับชำระเงิน การเผยแพร่จริงขึ้นกับสิทธิ์ TikTok และการยืนยันของเจ้าของบัญชี ไม่ใช่การรับรองว่าแอปผ่านการอนุมัติแล้ว

1. Who and what this notice covers

This notice describes the DoraConnect project website and the current invited, local-workspace test. The project is maintained through the GitHub account jpasstudio. The legal operator/controller identity and a dedicated private contact address must be confirmed before public onboarding. This notice does not claim that a multi-user public service is already operating.

Participants in the private test should contact the person who invited them through the same private channel. Do not submit personal data to this public website or public repository. See Contact & data requests.

2. Public website visits / การเข้าชมเว็บไซต์นี้

This is a static documentation site. It has no account registration, payment form, upload form, advertising tracker or application analytics script. It does not expose the private workspace, credentials, account database or user media.

The hosting provider, GitHub Pages, receives network requests and records visitor IP addresses for security. Opening external links, including GitHub support or TikTok pages, also sends requests to the destination service. Those services handle that information under their own notices. Read GitHub Pages data collection and the GitHub Privacy Statement.

3. Information in the private workspace / ข้อมูลในแอป

Depending on the features you use, the workspace stores account names/usernames, account settings, product and campaign details, user-entered measurements and sources, uploaded images, scripts, prompts, generated or imported media, selected character/voice settings, review decisions, job status and related audit records.

When an actual TikTok connection is authorized, the integration may receive an application-specific account identifier, profile fields, granted scopes and access/refresh tokens. Follower statistics are requested only when the relevant permission and monitoring function are enabled. A browser login to TikTok or a listed test username is not itself a token grant.

Workspace session cookies authenticate the local session. The app does not ask for your TikTok password, OTP, national-ID image or payment-card data. Tokens are held server-side in encrypted account-bound storage; this does not mean every database field, media file or backup is encrypted.

4. Why the information is used / วัตถุประสงค์

Information is used to maintain your requested workspace, bind each draft to the correct account, prepare and check content, render or import media, prevent accidental duplicate submissions, track user-confirmed delivery and troubleshoot failures. Only the scopes and operations applicable to the feature should be requested. Optional monitoring and external actions can be declined by not authorizing or starting them.

Any legal basis and controller-specific obligations for public operation must be documented before public onboarding. These private-test pages do not assert a blanket legal basis for all possible future uses. We do not authorize reuse of personal likenesses for impersonation or unrelated processing.

5. When information leaves the workspace / การส่งข้อมูลภายนอก

Local analysis or rendering communicates with the local services selected by the operator. An external media provider may receive the references, prompts and settings needed for an explicitly approved generation request. The provider and any cost/data-transfer confirmation should be visible before submission. Its own retention and use policies must be checked; no blanket claim that every external provider deletes data or never uses it for training is made here.

For a user-confirmed TikTok upload, the approved media and applicable request data are sent to TikTok. Tokens are used only for the authorized account. Upload-to-draft does not send every caption/privacy setting supported by Direct Post; the user completes those in TikTok. We do not publish private media or tokens into this documentation repository. Data previously delivered to an external service is also governed by that service's rules.

6. Storage, retention and backups / การเก็บรักษา

In the current build, workspace records and media are kept on the operator-controlled workstation, separately from this public site. Working copies or operator backups may retain records. The prototype does not implement a universal, timed automatic purge for all drafts, media, evidence and backups. It would be inaccurate to promise a 24-hour, 48-hour or 30-day deletion schedule that has not been implemented.

Disconnecting a TikTok account removes the application's stored connection when successful and stops its monitoring. It does not automatically delete earlier workspace content or remote TikTok posts. Before onboarding additional real participants, the operator must agree an appropriate retention and backup-deletion plan, limit collection to what is needed, and review data no longer required.

7. Access, correction, export and deletion / สิทธิและคำขอข้อมูล

Use the workspace's available edit/export/disconnect controls, or ask the private-test operator for assistance. The current one-click account deletion is intentionally blocked when dependent content, references, commerce records or posting history remain. A complete deletion request therefore requires review of those linked records and backups; it is not accomplished by merely disconnecting OAuth.

You may request information about access, correction, deletion, restriction, objection or export as applicable to your situation and law. The operator may need proportionate verification of control of the relevant account, but should not request passwords, tokens or identity-document copies through public support. The actual operator/contact and request-handling procedure must be completed before public use. Remote posts may need to be removed using the relevant platform's own controls.

8. Safety, updates and contacting the maintainer

The private test is intended for invited adults. Do not upload sensitive information, identity documents, confidential third-party data or media without the required rights. No system can guarantee absolute security. Report suspected unauthorized access through the existing private test contact rather than posting secrets publicly.

See Contact & data requests for the current contact scope. Material changes to processing or the service model must be explained before collecting additional data. The date above identifies this notice; it is not evidence of TikTok approval or legal certification.
